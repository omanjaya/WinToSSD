Pengujian di Windows — 25 Oktober 2026
Host: Windows 11 Home Single Language 26H2 (build 26300), Windows PowerShell 5.1.

LULUS: 44 pengujian logika di Windows PowerShell 5.1 (42 di atas + 2 pengujian exit code alat native).
LULUS: build ulang dengan .NET SDK 10.0.402; Engine.ps1 tertanam identik dengan source.
LULUS: aplikasi berjalan sebagai Administrator; daftar SSD USB, baca ISO, dan pemeriksaan tanpa format.
LULUS: pemeriksaan build host menolak ISO 26300 saat host masih build 26200.
LULUS: pemasangan end-to-end Windows 11 Pro 26300 (install.wim) mode UEFI ke SSD SATA 256 GB lewat adaptor USB:
       format, DISM apply + verify, BCDBoot, WinRE, verifikasi berkas boot, pelepasan drive letter.
LULUS: susunan partisi hasil: EFI 512 MiB, MSR 16 MiB, Windows NTFS, Recovery 3 GiB (satu MSR).

Diperbaiki selama pengujian:
- Native: PowerShell 5.1 menganggap baris stderr sebagai error fatal; kini hanya exit code yang menentukan.
- Langkah akhir: Set-Partition -NoDefaultDriveLetter ditolak untuk partisi Recovery; huruf drive kini dilepas dengan mountvol.
- Initialize-Disk GPT membuat MSR sendiri sehingga ada dua MSR; MSR bawaan kini dihapus lebih dulu.
- Tampilan: tombol Pasang Windows abu-abu saat nonaktif; baris rencana tidak lagi menyambung.

BELUM DIUJI: boot SSD di komputer tujuan.
BELUM DIUJI: mode Legacy BIOS/MBR, ISO install.esd, Windows 10, dan driver tambahan.
